Улучшенный, структурированный промпт для AI-агента:

---

## Задача
Создать одностраничное веб-приложение (SPA) — персональный трекер подготовки к вступительным экзаменам в ПНИПУ. Приложение должно быть реализовано как один HTML-файл со встроенными CSS и JavaScript (без сборщиков, без бэкенда). Все данные сохраняются локально в localStorage браузера, чтобы прогресс не терялся между сессиями.

## Ключевые даты
- **Дедлайн завершения подготовки:** 10 июля 2026, 17:00 (пермское время, UTC+5).
- **Начало экзаменов:** 13 июля 2026 (первый день экзаменов, пермское время).  
  Экзамены сдаются на базе профильного СПО по трём предметам:  
  Алгебра и начала математического анализа, Информационные технологии (далее — Информатика), Русский язык.

---

## Функциональные требования

### 1. Дедлайн-таймеры
- **Основной таймер:** обратный отсчёт до 10 июля 2026, 17:00 (UTC+5) в формате дни:часы:минуты:секунды.
- **Второй, более важный таймер:** отсчёт до начала экзаменов 13 июля 2026, 00:00 (UTC+5). Расположить под основным.
- **Цветовая индикация основного таймера:**  
  - зелёный — до дедлайна > 5 дней;  
  - жёлтый — осталось от 2 до 5 дней (включительно);  
  - красный — осталось < 2 дней.
- Время перерисовывается каждую секунду.

### 2. Ежедневная ротация предметов
- Три предмета автоматически чередуются по дням по циклу: Алгебра → Информатика → Русский → Алгебра …  
  Предмет дня определяется по количеству суток, прошедших с фиксированной стартовой даты (например, 01.07.2026), взятых по модулю 3.
- На главном экране ярко выделен блок **«Задачи сегодня»**, содержащий:
  - иконку или эмодзи текущего предмета;
  - прогресс-бар, показывающий долю изученных тем *этого* предмета (или выполненных заданий за день).
- Пользователь может вручную переключиться на любой предмет — тогда блок «Задачи сегодня» обновляется для выбранного предмета, но автоматический цикл не сбивается. При следующем открытии приложение возвращается к предмету по расписанию.

### 3. Контент по темам (жёстко зашит в JavaScript-структуру)
Подготовить три списка тем — по одному на каждый предмет. Каждая тема содержит один-два готовых шаблона заданий (квестов). Примерная структура данных:

```javascript
const subjects = [
  {
    id: 'algebra',
    name: 'Алгебра и начала мат. анализа',
    shortName: 'Алгебра',
    topics: [
      { title: 'Формулы сокращённого умножения', quests: ['Реши 10 задач на формулы сокращённого умножения', 'Повтори вывод основных формул'] },
      { title: 'Логарифмы: свойства, уравнения, неравенства', quests: ['Реши 15 логарифмических уравнений', 'Повтори свойства логарифмов и реши 10 неравенств'] },
      // ... остальные темы
    ]
  },
  // ...
];
```

**Темы для Алгебры и начал мат. анализа:**
- Формулы сокращённого умножения
- Логарифмы: свойства, уравнения, неравенства
- Тригонометрия: основное тождество, уравнения, формулы двойного угла
- Квадратные уравнения и неравенства
- Уравнения и неравенства с модулем
- Показательные уравнения и неравенства
- Иррациональные уравнения
- Уравнения с параметром
- Планиметрия (треугольники, трапеции, окружности, площади)

**Темы для Информатики (Информационные технологии):**
- Жизненный цикл разработки ПО
- Электронные таблицы: функции МАКС, СУММ, СЧЁТ, формулы
- ООП: наследование, инкапсуляция, полиморфизм
- Сети и протоколы, модель OSI
- Теория информации: формулы Шеннона и Хартли
- Базы данных: типы ключей, разграничение доступа
- Алгебра логики: таблицы истинности, конъюнкция / дизъюнкция / импликация
- Растровая и векторная графика
- Файловые системы и расчёт размера на диске (кластеры)
- Алгоритмы: разбор блок-схем

**Темы для Русского языка:**
- Орфография: приставки на З/С, непроизносимые согласные, Ъ после приставок, Н/НН
- Дефисное написание сложных слов
- Пунктуация: тире в простом предложении, запятые при однородных членах / деепричастных оборотах, двоеточие
- Сложноподчинённые предложения
- Прямая и косвенная речь
- Деепричастный оборот (типичные ошибки)
- Лексика: паронимы, синонимы, фразеологизмы, орфоэпия (ударения)

### 4. Задачи дня (квесты)
- При загрузке приложения в новый день для **текущего по ротации предмета** из его списка тем случайно выбираются 3–5 тем. Из соответствующих шаблонов формируется список квестов, который отображается в блоке «Задачи сегодня».
- Каждый квест — строка-описание + чекбокс. Отмеченный чекбокс означает выполнение задачи.
- Можно добавить собственную задачу через поле ввода и кнопку.
- При первой отметке задачи как выполненной (изменение состояния чекбокса с невыполненного на выполненное) начисляются очки опыта (XP). Одновременно прогресс по соответствующей теме внутри предмета увеличивается (тема считается полностью завершённой, когда выполнены все её обязательные квесты; прогресс-бар предмета показывает долю завершённых тем).
- Состояние задач, прогресс по темам и пользовательские задачи сохраняются в localStorage.

### 5. Геймификация
- **Очки опыта (XP) и уровни:**  
  - за каждую выполненную задачу — 10 XP;  
  - каждые 100 XP — повышение уровня (уровень отображается в интерфейсе).
- **Прогресс-бары предметов:**  
  - три отдельных прогресс-бара (Алгебра / Информатика / Русский), каждый показывает процент полностью завершённых тем.
- **Анимации:**  
  - при выполнении задачи или получении нового уровня — короткая ненавязчивая анимация (например, мини-конфетти, лёгкая вспышка или плавное изменение цвета).  
  - анимации должны радовать, но не отвлекать.

### 6. Дополнительные возможности
- **Быстрые ссылки:** блок с полезными ресурсами (РешуЕГЭ sdamgia.ru, другие сайты для тренировки тестов). Заранее добавить несколько ссылок.
- **Мини-статистика:**  
  - всего выполнено задач;  
  - средний темп (задач в день);  
  - осталось дней до 13 июля 2026;  
  - осталось незавершённых тем по всем предметам;  
  - простая тексто-цветовая оценка «успеваешь / нужно ускориться / рискуешь не успеть» (например, если оставшиеся темы делятся на оставшиеся дни — > 1.5 темы в день, то «нужно ускориться»).
- **Тёмная тема:** по умолчанию минималистичный тёмный интерфейс.
- **Сброс прогресса:** кнопка полного сброса всех данных с подтверждением (двойное нажатие или модальное окно).

## Дизайн и визуальный стиль
- **Тёмная, минималистичная тема:** чистые линии, много воздуха, без мультяшных персонажей и лишнего декора.
- **Шрифт:** моноширинный (например, JetBrains Mono, Courier New) или строгий sans-serif (Inter, Roboto).
- Прогресс-бары — аккуратные, одноцветные или с мягким градиентом.
- Уровни, XP и бейджи оформлены строго, без «детских» элементов.
- Все элементы хорошо читаются, приложение выглядит как профессиональный инструмент.

---

## Технические требования
- Весь код — один файл `index.html`.
- Без внешних зависимостей, без сборки, без сервера.
- Локальное хранение: все данные (выполненные задачи, прогресс тем, XP, уровень, пользовательские задачи, история) в `localStorage`.
- Приложение должно корректно определять дату в пермском часовом поясе (UTC+5).
- Логика ротации предметов должна учитывать, что новый день начинается в 00:00 по пермскому времени.
- При открытии в тот же день показываются сохранённые задачи (не генерируются заново), но если день сменился — задачи пересоздаются для нового предмета.
